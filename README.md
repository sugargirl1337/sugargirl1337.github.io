# Личное портфолио

Адаптивное портфолио независимого разработчика. Первый кейс — FORMA: лендинг, Telegram Mini App для бронирования и клиентский проморолик.

Статический сайт в `dist/`, без установки зависимостей и сборки. Главная страница — `dist/index.html`, стили — `dist/styles.css`. Новые работы добавляются на главную как отдельные кейсы. Контакт и персональное имя не указаны: пользователь их не предоставлял.

Изображения и видео скопированы из собственного проекта FORMA. Исходные изображения созданы с помощью ИИ; это указано в тексте кейса. Секреты Telegram, клиентские данные и серверный код бота в портфолио не включаются.

Локальный запуск: `python -m http.server 5180 --bind 127.0.0.1 --directory dist`.

При публикации сохранять проект из `.openai/hosting.json`. Авторские статические файлы `dist/` отслеживаются Git. Доступ к новому портфолио по умолчанию личный; изменение аудитории — отдельное действие.
