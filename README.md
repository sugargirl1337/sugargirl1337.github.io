# Личное портфолио

Адаптивное портфолио независимого разработчика. Сайт: https://sugargirl1337.github.io, связь в Telegram: @interpritattor.

Кейсы: FORMA (сайт салона с онлайн-записью, Mini App и ролик), TelemetryX (платформа телеметрии газа), сайт продукта TelemetryX для «Индустрии газов», «Ковёр» (лендинг кофейни и бот лояльности). Демо FORMA и «Ковра» лежат в `dist/projects/`; FORMA там работает в демо-режиме (`demo-api.js` отвечает на запросы к API прямо в браузере).

Статический сайт в `dist/`, без установки зависимостей и сборки. Главная страница — `dist/index.html`, стили — `dist/styles.css`. Новые работы добавляются на главную как отдельные кейсы. Публикуется на GitHub Pages сценарием `.github/workflows/pages.yml` из папки `dist/`.

Изображения и видео скопированы из собственного проекта FORMA. Исходные изображения созданы с помощью ИИ; это указано в тексте кейса. Секреты Telegram, клиентские данные и серверный код бота в портфолио не включаются.

Локальный запуск: `python -m http.server 5180 --bind 127.0.0.1 --directory dist`.

При публикации сохранять проект из `.openai/hosting.json`. Авторские статические файлы `dist/` отслеживаются Git. Доступ к новому портфолио по умолчанию личный; изменение аудитории — отдельное действие.
