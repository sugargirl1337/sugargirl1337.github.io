## Технологии

HTML, CSS, JavaScript, React, TypeScript, Cloudflare Workers, D1 / SQLite, Telegram Bot API, Telegram Mini Apps, grammY, Node.js.

## Для разработки

Сайт лежит в `dist/`, сборка не нужна. Локальный запуск:

```bash
python -m http.server 5180 --bind 127.0.0.1 --directory dist
```

Публикация на GitHub Pages идёт автоматически из `dist/` при каждом обновлении ветки `main`.

Изображения FORMA созданы с помощью ИИ, салон вымышленный. Секреты, клиентские данные и серверный код ботов в репозиторий не входят.
